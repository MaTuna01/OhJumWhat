오점왓 백엔드 API입니다. 화면(React)은 같은 출처에서 이 API를 부릅니다. 위의 「Select a definition」에서 **사용자 화면 API**와 **관리자 콘솔 API**를 고릅니다.

### Base URL

| 환경 | 주소 |
|---|---|
| 운영 | `https://www.ohjumwhat.cloud` (명세 화면은 운영에서 꺼져 있습니다) |
| 로컬(화면) | `http://localhost:5173` — Vite가 `/api`·`/oauth2`·`/login/oauth2`·`/logout`을 백엔드로 넘깁니다 |
| 로컬(백엔드) | `http://localhost:8080` — 이 명세 화면은 `/swagger-ui.html` |

- 경로 앞에 버전(`/api/v1`)을 붙이지 않습니다. 모든 API는 `/api/...`입니다. 화면과 서버를 한 이미지로 함께 배포하므로 버전을 나눌 일이 없습니다.
- 화면과 같은 출처라 CORS 설정이 없습니다. 다른 출처에서는 부를 수 없습니다.

### 인증: 세션 쿠키

- 토큰(JWT)을 쓰지 않습니다. 구글 로그인을 마치면 서버가 `SESSION` 쿠키(HttpOnly, SameSite=Lax, 30일)를 내리고, 브라우저가 저절로 보냅니다. `fetch`에 따로 넣을 값이 없습니다.
- 로그인은 API 호출이 아니라 **페이지 이동**입니다: `GET /oauth2/authorization/google`로 보내면 구글을 거쳐 항상 `/`로 돌아옵니다. 실패하면 `/login?error`, 강제 탈퇴로 차단된 계정은 `/login?error=blocked`로 돌아옵니다.
- 로그아웃: `POST /logout` → `204`(CSRF 헤더 필요).
- 로그인하지 않았거나 세션이 끝나면 `/api/**`는 모두 **`401`(본문 없음)**입니다. 리디렉션하지 않습니다. 화면은 401을 받으면 내 정보(`GET /api/me`)를 다시 받아 로그인 화면으로 보냅니다.
- 이 명세 화면의 「Try it out」은 같은 브라우저에서 로컬에 로그인해 두면 그 쿠키로 동작합니다(쿠키는 포트를 가리지 않습니다).

### CSRF

- 서버가 응답마다 `XSRF-TOKEN` 쿠키를 내립니다. **GET이 아닌 요청**에는 그 값을 `X-XSRF-TOKEN` 헤더로 붙입니다(화면의 `lib/api.ts`가 붙입니다).
- 없거나 다르면 `403 {"message": "보안 토큰이 만료됐어요. 새로고침한 뒤 다시 시도해 주세요."}`입니다.

### 오류 응답 형식

- 모든 오류는 `{"message": "사용자에게 그대로 보여줄 문구"}` 하나입니다. **`code` 필드는 없고**, 종류는 HTTP 상태 코드로 나눕니다. 문구는 화면에 그대로 보여 줘도 되게 씁니다.
- 예외: `401`은 본문이 없습니다. 예상하지 못한 서버 오류(`500`)는 Spring Boot 기본 형식입니다.

| 코드 | 뜻 |
|---|---|
| 400 | 요청 값이 틀렸어요(검증 실패, JSON 형식 오류, 잘못된 링크 등). 검증 실패는 처음 걸린 항목의 문구 하나만 줍니다 |
| 401 | 로그인하지 않았어요(본문 없음) |
| 403 | 권한이 없어요: 쓴 사람만 고칠 수 있는 글, 관리자 API, CSRF |
| 404 | 없어요. **조직 멤버가 아니어도 404**입니다(조직·투표가 있는지 알리지 않습니다) |
| 409 | 지금 상태에서는 안 돼요: 마감된 투표, 중복, 다른 사람의 요청과 겹침 등 |
| 413 | 올린 파일이 너무 커요(사진 5MB) |
| 423 | 관리자의 이용 제한(제재)으로 그 기능이 막혔어요. 문구에 끝나는 시각이 들어 있습니다 |
| 429 | 너무 자주 보냈어요(채팅·쪽지·방명록·사진의 속도 제한) |
| 503 | 바깥 서비스(카카오 지도 검색 등)를 잠시 쓸 수 없거나 사진 처리가 밀렸어요 |

### 권한 오류: 403과 404

- 조직 하위 API(투표·메뉴·채팅·정기 투표·통계·랭킹 등)는 먼저 조직 멤버인지 확인하고, 아니면 **404**입니다. 투표도 같습니다(투표가 없거나 그 조직 멤버가 아니면 404).
- **403**은 멤버이지만 그 일을 할 수 없을 때입니다: 남이 쓴 댓글·채팅 고치기, 관리자가 아닌데 `/api/admin/**`, CSRF 오류.
- 조직 안에는 관리자가 없습니다. 멤버는 모두 같은 권한입니다.

### 날짜·시간 형식

| 종류 | 형식 | 예시 |
|---|---|---|
| 시각(`…At`: `opensAt`, `closesAt`, `createdAt` 등) | ISO 8601, **UTC**(`Z`). 소수 초가 붙을 수 있습니다 | `2026-10-12T02:30:00Z` (= 한국 11:30) |
| 날짜(`pollDate`, 랭킹 `date` 등) | `YYYY-MM-DD`, **한국 날짜** | `2026-10-12` |
| 하루 안의 시각(마감 시간 입력, 정기 투표 `openTime`·`closeTime`) | `HH:mm`, **한국 시각** | `11:30` |

- "오늘", 마감, 정기 투표는 모두 한국 시간(KST) 기준으로 서버가 판정합니다. 화면은 받은 UTC 시각을 한국 시간으로 바꿔 보여 줍니다(`lib/time.ts`).
- 요일은 비트마스크입니다: 월=1, 화=2, 수=4, 목=8, 금=16, 토=32, 일=64(평일=31).

### 그 밖의 규칙

- 투표에 쓰는 API(메뉴 추가·삭제, 참여·패스·취소, 식당)는 모두 **최신 투표 상세**를 돌려줍니다. 화면은 그 응답을 그대로 캐시에 넣습니다.
- 진행 중인 투표에서만 쓸 수 있고, 마감되면 `409`입니다. 마감은 요청 시각이 `closesAt` 이후인지로 판정합니다(별도 상태 값 없음).
- 페이지: 지난 투표·방명록은 `page`(0부터), 채팅·쪽지는 `before`(그 ID보다 오래된 것)로 넘깁니다.
- 실시간: 투표 채팅 받기만 **WebSocket** `GET /api/polls/{pollId}/ws`(같은 출처 `wss://`, 세션 쿠키 인증, STOMP 없음)입니다. 서버가 `{"type": "created"|"updated"|"deleted", "message": {...}}`와 연결 확인용 `{"type": "ping"}`을 보냅니다. 보내기·고치기·지우기는 REST입니다. 닫는 코드 4001 = 채팅이 닫힘, 4003 = 로그아웃. 그 밖의 화면은 폴링합니다(투표 상세 3초).
- 사진 주소(`/api/photos/...`, `/api/chat-photos/...`)도 로그인이 필요합니다(`<img>`가 쿠키를 함께 보냅니다).
- 공개 헬스 체크: `GET /healthz` → `{"status": "UP"}`(로그인 불필요, 이 명세에는 없습니다).
