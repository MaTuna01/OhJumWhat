# 근처 식당을 찾고 지도로 볼 수 있어요
- 「＋ 식당」의 「근처에서 찾기」에서 메뉴 이름으로 조직 근처 식당을 찾아 바로 붙여 보세요. 메뉴를 정하기 전이라면 근처 식당을 둘러볼 수도 있어요.
- 투표 화면에 지도가 생겼어요. 메뉴마다 식당 위치와 인원이 핀으로 보이고, 「크게 보기」로 넓게 볼 수 있어요.
- 메뉴 카드에 조직 위치에서 식당까지 거리와 걸어서 걸리는 시간이 보여요.
- 같은 메뉴에 지난번 붙인 식당이 있으면 「지난번: 식당 이름」으로 알려 주고, 고르면 식당까지 함께 붙어요.
- 조직 설정의 「조직 위치」에서 조직 주소를 정해 주세요. 근처 식당 찾기와 지도는 이 주소를 기준으로 해요.
