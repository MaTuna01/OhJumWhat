# 메뉴 메이커 랭킹과 방명록이 생겼어요
- 조직의 「랭킹」 탭에서 내가 제안한 메뉴가 몇 번 채택됐는지 주간·월간 순위로 볼 수 있어요. 지난달 1위에게는 「🏅 이달의 메뉴 메이커」 배지가 붙어요.
- 투표가 끝나면 가장 많이 고른 메뉴에 「👑 채택」이 붙어요. 메뉴를 고른 사람이 멤버의 30%가 안 되면 채택되지 않아요.
- 멤버 이름이나 사진을 누르면 뜨는 프로필의 「방명록」 탭에 한 줄 글을 남길 수 있어요. 내 방명록에 새 글이 오면 위쪽 프로필 사진에 빨간 점이 떠요.
- 불편한 글이 내 방명록에 남으면 신고해 주세요.
